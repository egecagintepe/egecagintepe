<details>
<summary><b>▸ A closer look: system architecture, testing and responsibilities</b></summary>

**NovZon** — I coordinate product direction and the software platform. The public [architecture showroom](https://github.com/egecagintepe/novzon-platform) explains the major systems; proprietary production code remains private. Its frontend, service and asynchronous processing layers have different responsibilities.

**BoardMedic** — Python-based cross-platform command-line tooling, typed diagnostics, reproducible offline fixtures, and explicit guards for destructive operations. [Source and CI](https://github.com/egecagintepe/BoardMedic).

**ZonDPI** — Rust/C/Windows service components, local IPC, diagnostic CLI and desktop UI. [Source and releases](https://github.com/egecagintepe/ZonDPI).

**AuscultaForge** — In our senior-design team, my primary responsibility is the host application and recording-quality workflow: signal display, DSP, session persistence and repeatable software tests. Physical acoustic characterisation is **in progress**, not a completed clinical device. [Engineering scope](https://github.com/egecagintepe/ausculta-forge).

**TRIAGE & PromptlyAI** — Team/hackathon prototypes exploring offline coordination and LLM-guided interactions respectively. I distinguish prototype demonstrations from field-validated products.

**AI-assisted development** — I use AI tools for implementation, design exploration and review. Generated code, passing tests and independently measured real-world performance are different levels of evidence.

</details>
