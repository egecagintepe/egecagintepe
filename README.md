## How I tend to build

**Start with the system, not the stack.**  
Data flow, failure modes, state, recovery and the person operating the thing usually matter more than the framework choice.

**Automate repetition, keep judgment visible.**  
I use AI and automation heavily, but I prefer explicit checkpoints, validation and human approval over invisible magic.

**The interface counts as engineering.**  
A technically correct system that is painful to operate is still unfinished.
