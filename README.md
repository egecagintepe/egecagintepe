<details>
<summary><b>▸ A little more about how I work</b></summary>

- **Production systems:** I work on the architecture and operations of [NovZon](https://novzon.net), including reader experiences, backend workflows, background processing, and reliability improvements. Its [public showcase](https://github.com/egecagintepe/novzon-platform) documents the product without exposing private implementation details.
- **Embedded engineering:** In [AuscultaForge](https://github.com/egecagintepe/ausculta-forge), I contribute to firmware, the Windows host stack, the React interface, signal-processing software, and integration testing. Automated tests and real-world acoustic measurements are reported separately.
- **Dependable automation:** In my developer tools, I favor scoped permissions, deterministic checks, auditable changes, and human review for operations that could affect production systems.
- **AI-assisted development:** I use coding agents as engineering tools, not substitutes for testing or evidence. A passing test, a simulated result, and measured hardware behavior are not interchangeable.

</details>
